DISC สำหรับพยาบาลไทย

แบบประเมิน DISC ฉบับสั้น (21 ข้อ)

เลือกคำตอบที่ใกล้เคียงคุณที่สุดในสถานการณ์ทั่วไป ระบบจะสรุปผลและคำนวณคะแนนให้โดยอัตโนมัติ

เริ่มทำแบบสอบถาม 21 ข้อ ผู้ดูแลระบบ

แบบสอบถามฉบับสั้น (21 ข้อ)

คำชี้แจงผู้ทำแบบประเมิน

เลือกคำตอบ "ใกล้เคียงคุณที่สุด" ไม่ใช่ "สิ่งที่คุณคิดว่าควรทำ" ในสถานการณ์ทั่วไป ไม่ใช่วันที่เครียดสุดหรือดีสุด.

(สำหรับพิมพ์/อ้างอิง)
  1. เมื่อเริ่มเวรแล้วพบว่างานค้างหลายอย่าง แต่ยังไม่มีเหตุฉุกเฉิน คุณมักจะ…
    • A ดูภาพรวมเร็ว ๆ แล้วแบ่งงานที่ต้องทำก่อน เพื่อให้งานเดินต่อ
    • B ตรวจรายละเอียด งานที่ค้าง ผลตรวจ และจุดเสี่ยงก่อนวางแผน
    • C ถามทีมก่อนว่าใครติดอะไร แล้วช่วยจัดให้ทุกคนทำงานต่อได้
    • D ชวนทีมตั้งหลัก ลดความตึงเครียด แล้วเริ่มทำไปพร้อมกัน
  2. ถ้าวันหยุดมีธุระหลายอย่างต้องทำในวันเดียว คุณมักจะ…
    • A ทำรายการ จัดเส้นทาง เวลา และลำดับให้คุ้มที่สุด
    • B เลือกทำเรื่องสำคัญก่อน แล้วค่อยปรับหน้างาน
    • C ชวนคนไปด้วยหรือคุยกับคนใกล้ตัวให้วันนั้นไม่น่าเบื่อ
    • D เผื่อเวลาเยอะ ๆ ไม่อยากรีบหรือทำให้ใครลำบาก
  3. หลังเหตุการณ์วุ่นวายในวอร์ดจบลง คุณอยาก Feedback แบบไหนที่สุด…
    • A สรุปว่าอะไรต้องแก้ ใครรับผิดชอบ และต้องทำต่อเมื่อไร
    • B ทบทวนข้อมูล ขั้นตอน เวลา และจุดเสี่ยงที่อาจทำให้พลาด
    • C เปิดโอกาสให้ทีมพูดความรู้สึกและให้กำลังใจกัน
    • D ฟังทุกคนโดยไม่โทษกัน เพื่อให้ทีมรู้สึกปลอดภัย
  4. เมื่อต้องซื้อของชิ้นสำคัญ เช่น โทรศัพท์ เครื่องใช้ไฟฟ้า หรือของราคาแพง คุณมักจะ…
    • A เทียบสเปก รีวิว ราคา เงื่อนไขประกัน แล้วค่อยตัดสินใจ
    • B ถ้ารู้ว่าตอบโจทย์ ก็ซื้อเลย ไม่อยากเสียเวลานาน
    • C ถามเพื่อนหรือคนที่ใช้จริงก่อน เพราะอยากฟังประสบการณ์
    • D เลือกตัวที่ไว้ใจได้ ใช้ง่าย และไม่เสี่ยงมีปัญหาทีหลัง
  5. เมื่อต้องเรียนรู้อุปกรณ์หรือระบบใหม่ในงาน คุณมักจะ…
    • A ขอคู่มือ แนวทาง และข้อควรระวังก่อนเริ่มใช้
    • B ลองใช้จริงเร็ว ๆ เพื่อให้เข้าใจจากการลงมือทำ
    • C เรียนพร้อมเพื่อนหรือให้คนที่ใช้เป็นช่วยสอน
    • D ขอเวลาฝึกทีละขั้นจนมั่นใจก่อนใช้เอง
  6. ถ้าไปกินข้าวกับเพื่อนแล้วร้านที่ตั้งใจไปปิด คุณมักจะ…
    • A รีบเสนอร้านใหม่ใกล้ ๆ แล้วตัดสินใจให้จบ
    • B เปิดดูรีวิว เมนู ระยะทาง และราคา ก่อนเลือกร้านใหม่
    • C ชวนทุกคนเสนอความเห็นแล้วเลือกที่บรรยากาศดี
    • D เลือกร้านที่ทุกคนน่าจะกินได้ สบาย ๆ ไม่ยุ่งยาก
  7. เวลาส่งเวรให้คนที่มารับงานต่อ คุณมักจะเน้น…
    • A ข้อมูลครบ เรียงลำดับชัด มีผลตรวจและแผนต่อเนื่อง
    • B ประเด็นสำคัญ สิ่งที่ต้องทำต่อ และเรื่องที่ห้ามพลาด
    • C น้ำเสียงที่ช่วยให้ผู้รับเวรรู้สึกมั่นใจและกล้าถาม
    • D บริบทของคนไข้และสิ่งที่ทีมควรช่วยกันระวัง
  8. เวลาคุยในแชตกลุ่มเพื่อนหรือครอบครัว คุณมักจะ…
    • A ตอบสั้น ชัด เอาใจความสำคัญ
    • B พิมพ์ละเอียด อธิบายครบ เพื่อไม่ให้เข้าใจผิด
    • C ใช้คำพูดหรือสติ๊กเกอร์ให้บรรยากาศดี
    • D ตอบสุภาพ ระวังน้ำเสียง ไม่อยากให้ใครรู้สึกไม่ดี
  9. ถ้าคำสั่งการรักษาไม่ชัดเจน แต่ยังไม่ใช่ภาวะวิกฤต คุณมักจะ…
    • A รวบรวมข้อมูลที่เกี่ยวข้องก่อน แล้วถามกลับด้วยข้อมูลชัดเจน
    • B ติดต่อผู้สั่งทันทีให้ได้คำตอบ เพื่อไม่ให้เสียเวลา
    • C ปรึกษาคนในทีมก่อน เพื่อดูว่ามีใครเข้าใจบริบทเดียวกันไหม
    • D เลือกจังหวะสื่อสารอย่างสุภาพ เพื่อลดโอกาสเกิดความขัดแย้ง
  10. ถ้าต้องจัดทริปกับเพื่อนหลายคน คุณมักจะ…
    • A วางแผนเวลา งบ เส้นทาง และรายละเอียดให้ชัด
    • B ตัดสินใจสถานที่หลักก่อน แล้วค่อยแก้ระหว่างทาง
    • C เน้นกิจกรรมที่ทำให้ทุกคนสนุกและมีเรื่องคุยกัน
    • D เลือกแผนที่ไม่เหนื่อยเกินไป และไม่มีใครลำบากมาก
  11. เวลาสอนน้องใหม่ คุณมักจะ…
    • A ให้น้องลองทำภายใต้การดูแล แล้ว feedback ทันที
    • B อธิบายเหตุผล มาตรฐาน และข้อควรระวังให้เข้าใจก่อน
    • C สร้างบรรยากาศเป็นกันเอง ให้น้องกล้าถาม
    • D ค่อย ๆ สอนทีละขั้น อยู่ใกล้ ๆ จนกว่าน้องจะมั่นใจ
  12. ถ้าเพื่อนสนิทโทรมาระบายปัญหา คุณมักจะ…
    • A ช่วยสรุปปัญหา แล้วเสนอทางออกที่ทำได้จริง
    • B ถามรายละเอียดเพื่อเข้าใจสาเหตุและไม่ด่วนสรุป
    • C พูดให้กำลังใจ ช่วยให้เขารู้สึกดีขึ้นก่อน
    • D ฟังเงียบ ๆ อยู่เป็นเพื่อน และไม่เร่งให้เขาตัดสินใจ
  13. คนไข้หรือญาติเริ่มกังวลและถามซ้ำหลายรอบ คุณมักจะ…
    • A อธิบายเป็นขั้นตอน ตรวจความเข้าใจ และให้เวลาถามเพิ่ม
    • B สรุปข้อมูลสำคัญให้ตรงประเด็น และบอกขั้นตอนต่อไปชัด ๆ
    • C รับฟังก่อน สะท้อนความกังวล แล้วค่อยอธิบาย
    • D ใช้น้ำเสียงเป็นมิตร ช่วยเปลี่ยนบรรยากาศให้ผ่อนคลาย
  14. ถ้าต้องทำงานบ้านร่วมกับคนอื่น คุณมักจะ…
    • A แบ่งงานให้ชัดว่าใครทำอะไร และอยากให้เสร็จเร็ว
    • B กำหนดวิธีทำให้เรียบร้อย ถูกต้อง และไม่ต้องกลับมาแก้
    • C เปิดเพลง คุยเล่น หรือทำให้บรรยากาศไม่น่าเบื่อ
    • D ช่วยส่วนที่คนอื่นไม่ถนัด และพยายามไม่ให้ใครรู้สึกโดนบังคับ
  15. ในที่ประชุมวอร์ด คุณมักจะมีบทบาทแบบใด…
    • A เสนอประเด็นที่ควรตัดสินใจให้ชัด เพื่อให้งานเดินต่อ
    • B ถามรายละเอียด ความเสี่ยง หรือหลักฐานที่ใช้สนับสนุน
    • C ช่วยเชื่อมความคิดเห็นของหลายฝ่ายให้คุยกันง่ายขึ้น
    • D สนับสนุนให้ทุกคนได้พูด โดยเฉพาะคนที่ไม่ค่อยกล้าออกความเห็น
  16. ถ้ามีคนวิจารณ์งานหรือสิ่งที่คุณทำ คุณมักจะ…
    • A ถามทันทีว่าต้องแก้อะไร แล้วจัดการให้จบ
    • B ขอเหตุผล ตัวอย่าง หรือข้อมูลที่ชัดเจนก่อนรับข้อสรุป
    • C คุยต่อเพื่อให้เข้าใจเจตนา และพยายามรักษาความสัมพันธ์
    • D ใช้เวลาตั้งหลักก่อน แล้วค่อยกลับไปแก้อย่างระมัดระวัง
  17. เมื่อแผนงานในวอร์ดเปลี่ยนกะทันหัน คุณมักจะ…
    • A รีบมองหาแผนใหม่ที่ใช้งานได้ทันที
    • B เช็กผลกระทบ ความเสี่ยง และข้อมูลที่ยังไม่ครบ
    • C คุยกับทีมเพื่อให้ทุกคนเข้าใจตรงกันและลดความตึงเครียด
    • D ขอให้กำหนดขั้นตอนใหม่ให้ชัด เพื่อให้ทุกคนทำต่อได้มั่นใจ
  18. ถ้าอยู่ในสถานที่ใหม่ที่ไม่คุ้น เช่น เมืองใหม่ งานประชุม หรืออาคารราชการ คุณมักจะ…
    • A เดินสำรวจเอง ถามทางเมื่อจำเป็น แล้วไปต่อให้ถึงเป้าหมาย
    • B เปิดแผนที่ อ่านป้าย เช็กชั้น/ห้อง/เส้นทางให้แน่ใจก่อน
    • C ถามคนแถวนั้นหรือชวนคนไปด้วย จะได้ไม่รู้สึกเกร็ง
    • D ค่อย ๆ ไปตามขั้นตอน เลือกทางที่ปลอดภัยและไม่เสี่ยงหลง
  19. ถ้าเกิด near miss ในหน่วยงาน คุณมักอยากเริ่มจาก…
    • A กำหนดมาตรการแก้ไขทันทีเพื่อไม่ให้เกิดซ้ำ
    • B วิเคราะห์ root cause ข้อมูล ขั้นตอน และจุดควบคุม
    • C คุยกับทีมให้เปิดใจว่าเกิดอะไรขึ้นโดยไม่โทษกัน
    • D ดูว่าคนที่เกี่ยวข้องต้องการการช่วยเหลืออะไรบ้าง
  20. เมื่อมีเวลาว่างหลังเลิกงาน คุณมักจะชอบ…
    • A ทำกิจกรรมที่รู้สึกว่าคุ้มค่า ได้ผลลัพธ์ หรือเคลียร์เรื่องค้าง
    • B อ่าน ดูข้อมูล จัดของ วางแผน หรือทำอะไรที่ต้องใช้สมาธิ
    • C เจอคน คุย เล่นโซเชียล หรือทำกิจกรรมที่มีสีสัน
    • D พักแบบสงบ ๆ ทำอะไรที่คุ้นเคย ไม่ต้องใช้พลังมาก
  21. หลังจบเวรหรือจบวันที่เหนื่อยมาก คุณมักจะคิดทบทวนเรื่องใดมากที่สุด…
    • A วันนี้อะไรทำให้ช้า และครั้งหน้าจะทำให้เร็วขึ้นอย่างไร
    • B มีจุดไหนที่ข้อมูลไม่ครบหรืออาจพลาดได้อีกไหม
    • C วันนี้บรรยากาศทีมเป็นอย่างไร ใครดูเครียดหรือหมดพลังไหม
    • D ทุกคนผ่านวันนี้ไปได้ดีไหม และมีใครควรได้รับการช่วยเหลือต่อไหม

กฎการแปลผล: คุณคือคนแบบไหนในวอร์ด?

เมื่อรวมคะแนนมิติ DISC แล้ว ให้ดูว่ามิติใดได้คะแนนสูงสุด แล้วดูคำทำนายด้านล่างนี้:

🐂 กระทิง (D)

(ผู้นำจอมพลัง ผู้มุ่งมั่นพิชิตเป้าหมาย / Dominance)

  • นิยาม: เปรียบเสมือน กระทิง ที่มีพละกำลังมหาศาล พร้อมพุ่งชนเป้าหมาย ชอบความรวดเร็ว และไม่เกรงกลัวอุปสรรค
  • จุดแข็งในงานพยาบาล: ตัดสินใจเด็ดขาดในภาวะวิกฤต (เช่น CPR) ทำงานแข่งกับเวลาได้ดีมาก แก้ปัญหาเฉพาะหน้าเก่ง เน้นผลลัพธ์ว่า "คนไข้ต้องรอด" หรือ "งานต้องเสร็จ"
  • ข้อควรระวัง: อาจเผลอใช้อารมณ์หรือคำพูดที่ดุดัน สั้นห้วน จนเพื่อนร่วมงานรู้สึกกลัว หรือลืมใส่ใจรายละเอียดเล็กน้อยเพราะมุ่งแต่เป้าหมายหลัก
  • บทบาทที่เหมาะสม: หัวหน้าเวร, พยาบาล ER/ICU, หรือทีม Code Blue ที่ต้องการความเฉียบขาด

🦅 อินทรี (I)

(นักวิสัยทัศน์ ผู้สร้างแรงบันดาลใจ / Influence)

  • นิยาม: เปรียบเสมือน นกอินทรี ที่บินสูง มองเห็นภาพรวมกว้างไกล รักอิสระ ชอบเรียนรู้สิ่งใหม่ๆ และมีทักษะการสื่อสารที่ยอดเยี่ยม
  • จุดแข็งในงานพยาบาล: สร้างบรรยากาศเชิงบวกในวอร์ดได้เก่ง ประสานงานกับสหสาขาวิชาชีพได้ราบรื่น มีวาทศิลป์ในการพูดคุยให้กำลังใจคนไข้และญาติ มองเห็นโอกาสในการพัฒนางานใหม่ๆ
  • ข้อควรระวัง: อาจเบื่อง่ายกับงานเอกสารซ้ำๆ (Routine) หรือมัวแต่คุยโปรเจกต์ใหม่จนลืมลงรายละเอียดในเนื้องานปัจจุบัน
  • บทบาทที่เหมาะสม: งานประชาสัมพันธ์, ทีมรับรองคุณภาพ (HA) ด้านการสื่อสาร, หรือหน่วยงานที่ต้องดีลกับคนเยอะๆ

🐭 หนู (S)

(ผู้ประสานใจ ผู้ดูแลด้วยความห่วงใย / Steadiness)

  • นิยาม: เปรียบเสมือน หนู ตัวเล็กที่ว่องไวแต่อ่อนโยน ช่างสังเกตความรู้สึก ชอบอยู่รวมกันเป็นกลุ่ม รักความสงบ และดูแลใส่ใจคนรอบข้างเสมอ
  • จุดแข็งในงานพยาบาล: มีความเห็นอกเห็นใจสูง เป็นผู้ฟังที่ดีเยี่ยม รับรู้อารมณ์คนไข้ได้ไว ให้การพยาบาลที่นุ่มนวลและใส่ใจรายละเอียดทางจิตใจ เพื่อนร่วมงานรักเพราะช่วยเหลือเก่ง
  • ข้อควรระวัง: ขี้เกรงใจ ไม่กล้าปฏิเสธจนงานล้นมือ หรือเก็บความเครียดไว้คนเดียว ไม่ชอบความขัดแย้งและการเปลี่ยนแปลงกะทันหัน
  • บทบาทที่เหมาะสม: พยาบาลพี่เลี้ยง (Preceptor), ดูแลผู้ป่วยเรื้อรัง/ประคับประคอง (Palliative), หรือจิตเวช

🧸 หมี (C)

(นักวิเคราะห์ ผู้รักษากฎระเบียบ / Conscientiousness)

  • นิยาม: เปรียบเสมือน หมี ที่มั่นคง หนักแน่น ใช้เวลาในการไตร่ตรอง วางแผนอย่างรอบคอบ ยึดมั่นในหลักการ ทฤษฎี และความปลอดภัยสูงสุด
  • จุดแข็งในงานพยาบาล: ทำงานเป็นระบบระเบียบมาก ข้อมูลแน่น (Evidence-based) แม่นยำเรื่องยาและคำนวณ ความผิดพลาดน้อยมาก ยึดถือมาตรฐานวิชาชีพอย่างเคร่งครัด
  • ข้อควรระวัง: อาจใช้เวลาตัดสินใจนานเพราะต้องการข้อมูลที่สมบูรณ์แบบ (Perfectionist) หรือดูเคร่งขรึม เข้าถึงยากในสายตาน้องๆ อาจหงุดหงิดง่ายถ้าเห็นอะไรไม่เป็นระเบียบ
  • บทบาทที่เหมาะสม: งานควบคุมการติดเชื้อ (IC), งานประกันคุณภาพ, ห้องผ่าตัด, หรือเภสัชกรรม

ตารางสรุปสัตว์ 4 ทิศในบริบทพยาบาล

สัญลักษณ์ สัตว์ สไตล์ จุดเด่น สิ่งที่กลัว
กระทิง (D)กระทิง 🐂Dominanceเป้าหมาย, รวดเร็ว, พุ่งชนการถูกควบคุม, ความล้มเหลว
อินทรี (I)อินทรี 🦅Influenceภาพรวม, สื่อสาร, สร้างสรรค์การถูกเพิกเฉย, การสูญเสียอิทธิพล
หนู (S)หนู 🐭Steadinessใส่ใจ, สัมพันธ์, ปรองดองการเปลี่ยนแปลงกะทันหัน, ความขัดแย้ง
หมี (C)หมี 🧸Complianceหลักการ, ระเบียบ, ข้อมูลความผิดพลาด, การถูกวิจารณ์

คำอธิบาย 4 มิติ + แนวทางใช้ในงานพยาบาล

D (Dominance) = กระทิง

ภาพรวม: ตรงไปตรงมา กล้าตัดสินใจ และมุ่งผลลัพธ์ชัดเจน เหมือน “นักรบ” ที่พร้อมเผชิญปัญหา.

พฤติกรรมเด่น: ชอบลงมือเอง เคลื่อนไหวเร็ว ชอบเห็นผลเร็ว กล้าเผชิญหน้าและแสดงจุดยืน.

ข้อดี: เด็ดเดี่ยว ปกป้องทีม กล้ารับผิดชอบในสถานการณ์กดดัน.

ข้อควรพัฒนา: ชะลอการตัดสินใจในบางเรื่อง รับฟังมากขึ้น และทบทวนก่อนสั่งการเพื่อไม่ให้ดูใช้อำนาจเกินไป.

I (Influence) = อินทรี

ภาพรวม: เข้าสังคมเก่ง ช่างพูด มีพลังบวก และถนัดสร้างบรรยากาศที่ดีให้ทีม.

พฤติกรรมเด่น: มองภาพใหญ่ คิดสร้างสรรค์ ชอบไอเดียใหม่ และเชื่อมโยงคนเก่ง.

ข้อดี: สร้างแรงจูงใจและความร่วมมือได้ดี ทำให้งานมีสีสันและคล่องตัว.

ข้อควรพัฒนา: ฝึกจัดลำดับความสำคัญ เก็บรายละเอียด และโฟกัสงานให้จบเป็นเรื่อง ๆ.

S (Steadiness) = หนู

ภาพรวม: สุภาพ อบอุ่น ใจเย็น และให้ความสำคัญกับความสัมพันธ์และความรู้สึกของคนรอบตัว.

พฤติกรรมเด่น: ชอบช่วยเหลือ ประสานงานเก่ง รับฟังดี และหลีกเลี่ยงความขัดแย้งรุนแรง.

ข้อดี: เป็นกาวใจของทีม ช่วยลดแรงปะทะ ทำให้ทีมทำงานร่วมกันได้ราบรื่น.

ข้อควรพัฒนา: ฝึกยืนยันจุดยืน กล้าตัดสินใจในบทบาทผู้นำ และตั้งขอบเขตเมื่อถูกกดดัน.

C (Conscientiousness) = หมี

ภาพรวม: ช่างวิเคราะห์ มีหลักการสูง รอบคอบ และให้คุณค่ากับความถูกต้องเป็นระบบ.

พฤติกรรมเด่น: ชอบวางแผนเป็นขั้นตอน ใช้เหตุผลสูง คิดล่วงหน้า และไม่ชอบความเสี่ยงที่ไม่จำเป็น.

ข้อดี: ลดความผิดพลาดได้ดี เหมาะกับงานที่ต้องการมาตรฐานและความแม่นยำ.

ข้อควรพัฒนา: เพิ่มความยืดหยุ่นเมื่อต้องเปลี่ยนแผน และลดความเคร่งเครียดจากความเป๊ะเกินไป.

การแปลผลแบบคู่สไตล์ (Top 2)

  • D/i: มุ่งผล + โน้มน้าวเก่ง ระวังพูดเร็ว/แรง
  • i/D: เข้าหาคน + กล้าชน ระวังใจร้อน
  • D/C: เด็ดขาด + มาตรฐานสูง ระวังเคร่ง
  • C/D: วิเคราะห์ + กล้าตัดสิน ระวังช้าเมื่อข้อมูลไม่ครบ
  • D/S: เร็วแต่ยังคุมความนิ่งได้ ระวังทีมสับสน
  • S/D: ใจเย็นแต่ยืนหลักได้ ระวังเก็บอารมณ์
  • i/S: เป็นมิตร อบอุ่น ประสานทีมเก่ง ระวังเลี่ยงขัดแย้ง
  • S/i: สุขุมแต่เข้าถึงง่าย ระวังไม่กล้าพูดสิ่งยาก
  • i/C: สื่อสารดี + มีเหตุผล ระวังเครียดเมื่อรายละเอียดไม่พร้อม
  • C/i: ข้อมูลแน่น + คุยรู้เรื่อง ระวังวิจารณ์มากไป
  • S/C: มั่นคง + รอบคอบ ระวังช้าเมื่อมีแรงกดดัน
  • C/S: ระเบียบ + ใจเย็น ระวังต้านการเปลี่ยนแปลง

ทำความเข้าใจโมเดล DISC

แบบย่อ

เหมาะกับเวิร์กช็อประยะสั้น ให้ผลลัพธ์รวดเร็ว โดยระบุสไตล์หลัก (และอาจมีสไตล์รอง) เช่น “คุณเป็นสไตล์ i และมีแนวโน้ม S”

แบบละเอียด

แสดงคะแนนครบทั้ง 4 มิติ พร้อมเปอร์เซ็นต์หรือกราฟสรุป เพื่อวิเคราะห์ความผสมของบุคลิก อย่างละเอียด เช่น “SC” หรือ “DI”

D: เด็ดขาด ผลลัพธ์นำ i: เข้าสังคม สร้างพลังทีม S: มั่นคง ใส่ใจคน C: รอบคอบ มาตรฐานสูง

เหตุใด DISC จึงสำคัญกับพยาบาล

งานพยาบาลต้องทำงานเป็นทีม ภายใต้ความกดดัน และกับผู้ป่วยที่หลากหลาย DISC ช่วยให้เข้าใจตนเองและผู้อื่น ปรับการสื่อสารให้ตรงคน ลดความขัดแย้ง ทำงานราบรื่นขึ้น และยกระดับคุณภาพการดูแลผู้ป่วย

4 มิติของ DISC

  • D(กระทิง) – มุ่งผลลัพธ์ ตัดสินใจเร็ว เด็ดขาด ตรงประเด็น แก้ปัญหาไว เหมาะสถานการณ์เร่งด่วน
    ระวัง: อาจตรงหรือกดดันคนอื่นเกินไป
  • I(อินทรีย์) – มุ่งความสัมพันธ์และการจูงใจ สื่อสารดี สร้างบรรยากาศทีม โน้มน้าวเก่ง
    ระวัง: ไม่ชอบรายละเอียด เสียสมาธิง่าย
  • S(หนู) – มุ่งความร่วมมือและความสม่ำเสมอ ใจเย็น รับฟังดี ดูแลต่อเนื่อง สร้างความมั่นคงให้ทีม
    ระวัง: ไม่ชอบความขัดแย้ง ตัดสินใจช้าเมื่อถูกกดดัน
  • C(หมี) – มุ่งความถูกต้องและคุณภาพ ละเอียด เป็นระบบ วิเคราะห์ดี ลดความผิดพลาด
    ระวัง: กลัวผิดพลาด สื่อสารน้อย ดูเข้มงวด

คู่สไตล์ — คนส่วนใหญ่ไม่ใช่แบบเดียว

  • D(กระทิง)I(อินทรีย์) – กล้าตัดสินใจ + จูงใจเก่ง พลังสูง นำทีมดี แต่ไม่ชอบรายละเอียด
  • S(หนู)C(หมี) – สุขุม + ละเอียด ทำงานรอบคอบ เสถียร แต่ปรับตัวช้าเมื่อเปลี่ยนเร็ว
  • iS(หนู) – เป็นมิตร อดทน ทำงานกับคนดี
  • C(หมี)D(กระทิง) – จริงจัง ละเอียด ตัดสินใจบนข้อมูล

การดู “คู่สไตล์” ทำให้เข้าใจคนลึกกว่า ไม่เหมารวม

ใช้ DISC ในงานพยาบาล (ภาคปฏิบัติ)

วอร์ดทั่วไป
D(กระทิง) ตัดสินใจเร็วในเหตุฉุกเฉิน, C(หมี) ตรวจความถูกต้องยา/อุปกรณ์, I(อินทรีย์) สื่อสารกับญาติ/ทีม, S(หนู) ดูแลผู้ป่วยใกล้ชิด
ผล: แบ่งบทบาทตามจุดแข็ง ลดซ้ำซ้อน ลดขัดแย้ง

หน่วยเฉพาะทาง / ห้องผ่าตัด

ผล: งานแม่นยำ ทีมเข้าใจกัน ความเครียดลดลง

ผล: ตัดสินใจดี + ปลอดภัย + ทีมยังทำงานได้แม้เครียดสูง

ประโยชน์หลัก

  • สื่อสารดีขึ้น ทีมเวิร์กดีขึ้น
  • ดูแลผู้ป่วยตรงความต้องการมากขึ้น
  • พัฒนาบุคลากรและผู้นำ
  • ลดความเครียดและความขัดแย้ง

ข้อจำกัด

  • ไม่ใช่วัดความสามารถ และไม่ควรติดป้ายคน
  • ผลขึ้นกับการตอบและการตีความ
  • ใช้ผิดอาจกลายเป็นอคติ
  • ต้องคำนึงบริบทวัฒนธรรม
  • เป็น “เครื่องมือหนึ่ง” ไม่ใช่ทั้งหมด

การนำผลลัพธ์ DISC ไปใช้พัฒนาทีมงานพยาบาลในวอร์ด

การนำผลลัพธ์จากแบบประเมิน DISC (ในบริบทสัตว์ 4 ทิศ: กระทิง, อินทรี, หนู, หมี) ไปใช้พัฒนาทีมงานพยาบาลในวอร์ด สามารถทำได้โดยเน้นการ "ใช้คนให้ถูกงาน" และ "สื่อสารให้ถูกจริต" ซึ่งจะช่วยลดความขัดแย้งและเพิ่มประสิทธิภาพการดูแลผู้ป่วยได้จริง

1) การจัดมอบหมายงานให้ตรงกับจุดแข็ง

การรู้ว่าพยาบาลแต่ละคนเป็น “สัตว์” ชนิดไหน ช่วยให้หัวหน้าหอผู้ป่วยมอบหมายบทบาทได้เหมาะสมยิ่งขึ้น:

  • 🐂 กลุ่มกระทิง (D - Dominance)
    งานที่เหมาะสม: ผู้นำทีม (Team Leader) ในเวรดึก/ภาวะวิกฤต เช่น Code Blue, งานที่ต้องการผลลัพธ์รวดเร็ว เช่น บริหารจัดการเตียง หรือเคลียร์ข้อร้องเรียนที่ต้องการความเด็ดขาด
    การพัฒนา: ตั้งเป้าหมายท้าทาย แต่เตือนเรื่องความละเอียดอ่อนทางอารมณ์กับเพื่อนร่วมงาน
  • 🦅 กลุ่มอินทรี (I - Influence)
    งานที่เหมาะสม: งานประชาสัมพันธ์, กิจกรรมสันทนาการในวอร์ด, ผู้นำกลุ่มบำบัด/สอนสุขศึกษา เพราะสื่อสารโน้มน้าวและสร้างบรรยากาศบวกได้ดี
    การพัฒนา: ฝึกลงรายละเอียดและติดตามงานให้จบ เพื่อลดปัญหาเริ่มเก่งแต่ปิดงานยาก
  • 🐭 กลุ่มหนู (S - Steadiness)
    งานที่เหมาะสม: พี่เลี้ยง (Preceptor), ดูแลผู้ป่วย Palliative, งาน Routine/เอกสารที่ต้องการความสม่ำเสมอสูง
    การพัฒนา: สนับสนุนให้กล้าแสดงความคิดเห็น และระวังภาระงานเกินตัว (Burnout)
  • 🧸 กลุ่มหมี (C - Compliance/Conscientiousness)
    งานที่เหมาะสม: ประกันคุณภาพ (HA/QA), ควบคุมการติดเชื้อ (IC), ตรวจสอบคำสั่งการรักษาและยา
    การพัฒนา: ลดความเครียดจาก Perfectionism และฝึกยืดหยุ่นในสถานการณ์ที่ไม่วิกฤต

2) การปรับวิธีการสื่อสารในทีม

ปัญหาหลักในวอร์ดมักมาจาก “สื่อสารผิดรูปแบบ” การเข้าใจ DISC จะช่วยสร้าง ภาษากลาง ในทีม:

  • คุยกับกระทิง (D): “สั้น กระชับ ตรงประเด็น” — บอกปัญหา สิ่งที่ต้องทำ และผลลัพธ์ที่ต้องการ (เช่น SBAR)
  • คุยกับอินทรี (I): “เป็นกันเอง เปิดพื้นที่ให้แสดงไอเดีย” — เริ่มด้วยบรรยากาศผ่อนคลาย แล้วค่อยเข้าเรื่องงาน
  • คุยกับหนู (S): “นุ่มนวล เป็นขั้นตอน ให้ความมั่นใจ” — ไม่เร่งรัดหรือกดดันเกินจำเป็น
  • คุยกับหมี (C): “ข้อมูลพร้อม อ้างอิงหลักการ” — ใช้ข้อเท็จจริงและให้เวลาคิดวิเคราะห์ก่อนตอบ

3) การบริหารความขัดแย้ง (Conflict Resolution)

  • กระทิง vs หมี: ขัดกันเรื่อง “ความเร็ว” vs “ความละเอียด” → ทางแก้: ตกลง Deadline และมาตรฐานขั้นต่ำร่วมกัน
  • กระทิง vs กระทิง: แย่งบทนำ/แย่งกันพูด → ทางแก้: แบ่งขอบเขตอำนาจหน้าที่ (Zone) ให้ชัดเจน

4) การสร้างสมดุลทีม

  • หนูเยอะเกินไป: ทีมสงบและกลมเกลียว แต่เปลี่ยนแปลงยาก/ตัดสินใจวิกฤตช้า
  • กระทิงเยอะเกินไป: งานเร็วมาก แต่บรรยากาศตึงเครียดและโต้เถียงบ่อย
  • แนวทาง: จัดเวรให้คละสไตล์ เช่น มีกระทิงนำทีม มีหนูประสานงาน และมีหมีตรวจสอบยา

สรุป

การใช้ DISC ในวอร์ดไม่ใช่การตีตราว่าใครเป็นคนอย่างไร แต่เพื่อเข้าใจ แรงจูงใจ และ ความกลัว ของสมาชิกทีม เพื่อให้หัวหน้าดูแลใจและใช้งานทีมได้อย่างมีประสิทธิภาพสูงสุด
